# NeuroAI Mini-Project

This repository contains a reproducible pipeline for applying AI methods to neurodegenerative and brain-tumor data using open, lightweight datasets.

## Directory Layout
| Folder | Description |
|---------|--------------|
| notebooks/ | Jupyter notebooks (01_data → 06_report) |
| data/ | Public datasets (not tracked in git) |
| artifacts/ | Generated models, metrics, figures (not tracked) |

## Quickstart
1. Create a Python 3.10 environment.
2. `pip install -r requirements.txt`
3. Launch Jupyter Lab or Colab and run `notebooks/01_data.ipynb`.
